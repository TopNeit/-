# РЖЯ динамические жесты → текст и голос

## Что делает приложение
`gesture_rjy_app.py` захватывает видео с веб-камеры, отслеживает до двух рук через MediaPipe Hands, распознаёт динамические жесты и выводит результат в текст + озвучивает его через `pyttsx3`.

## Быстрый запуск
```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python gesture_rjy_app.py
```

## Режимы распознавания
1. **ML-режим (рекомендуется)**: положите в папку проекта `model.h5` и `labels.txt`.
2. **Fallback-режим (без модели)**: используется расширенный словарь эвристик из 16 фраз:
   - ПРИВЕТ, ПОКА, ДА, НЕТ, СПАСИБО, ПОЖАЛУЙСТА, Я, ТЫ,
   - МЫ, СТОП, ПОМОГИ, ОТЛИЧНО, ВПРАВО, ВЛЕВО, ВВЕРХ, ВНИЗ.

## Как добиться точности >= 90%
Точность 90%+ достигается именно обученной sequence-моделью (LSTM/GRU/Transformer) на качественном датасете:
- нормализованные landmarks (позиция/масштаб),
- баланс классов и разные исполнители,
- аугментации по времени,
- temporal voting/smoothing на инференсе.

## История
Все распознавания автоматически пишутся в `history.txt` (текст + время).

## База данных 1000+ слов
При первом запуске автоматически создаётся `lexicon.db` (SQLite) c **1000+** токенов/слов и числовых фраз.
Если ML-модель возвращает числовой ID класса, приложение преобразует его в слово из базы.
